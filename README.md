# albertstein.link

Personal site and lab notebook of Alberto Galliani. Static HTML, no build step, deployed on Cloudflare Pages from this repository.

- `site/` is what gets published. Output directory for Pages: `site`.
- `site/data/progress.json` drives the progress bar, the mission list and the "skills earned" section of the CV.
- `missioni/` contains the guided steps (in Italian).

Every commit on `main` goes live at https://albertstein.link within a minute.
