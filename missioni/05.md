# Missione 5: postazione locale

**Cosa ottieni:** lavori sul sito dal tuo PC con git da terminale, e non più dal browser.

**Perché conta:** Linux e terminale sono il pane di chi fa rete e sistemi. Da qui in poi il modo in cui lavori è già il modo in cui lavorerai.

## Passi

1. Se il PC è Windows: installa WSL2 con Ubuntu. Se è già Linux, meglio.
2. Installa `git` e `curl`. Configura nome ed email: `git config --global user.name` e `user.email` (la stessa email di GitHub).
3. Crea una chiave SSH (`ssh-keygen -t ed25519`), aggiungi la chiave pubblica su GitHub, verifica con `ssh -T git@github.com`. Scrivi due righe su cos'è la chiave pubblica e cosa non devi mai condividere.
4. `git clone` del repository via SSH. Apri il sito in locale: nella cartella `site`, `python3 -m http.server 8080` e vai su `http://localhost:8080`.
5. Crea un branch, modifica un file con un editor da terminale (nano va bene, poi prova vim), `git add`, `git commit`, `git push`. Apri la PR da GitHub, merge.
6. Prova anche: `git log --oneline`, `git diff`, `git status`. Devono diventare riflessi.
7. Segna la missione come fatta, dal terminale.

## È fatta quando

- Il commit di chiusura è stato fatto dal PC, con push via SSH.
- Sai aprire il sito in locale prima di fare push.

## Riga che entra nel CV

Linux command line, Git CLI, SSH keys

## Se ti blocchi

> Sto configurando Linux (o WSL2) per lavorare con git da terminale: chiave SSH, clone, branch, commit, push. Guidami passo passo ma spiega ogni comando prima che lo esegua, e chiedimi l'output per capire se è andato bene. Non darmi script pronti da copiare.
